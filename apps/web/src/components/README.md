# Componentes reutilizáveis

Os componentes visuais comuns ficam aqui. As regras de negócio de eventos
vivem em [`../features/events/`](../features/README.md), enquanto este diretório
fornece a moldura e os widgets partilhados.

| Pasta | Responsabilidade |
| --- | --- |
| [`backoffice/`](backoffice/README.md) | Shell, navegação visual e contexto do município. |
| [`button/`](button/README.md) | Helpers de publicação/despublicação por `PATCH`. |
| [`filters/`](filters/README.md) | Botão genérico para repor filtros. |
| [`map/`](map/README.md) | Mapa Leaflet, marcadores, agrupamento e ícones por tipo. |
| [`statCards/`](statCards/README.md) | Cartões/contadores de eventos para o cabeçalho do workspace. |
